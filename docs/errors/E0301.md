# E0301 — sai kiểu / số đối số / biểu thức chưa có ngữ nghĩa ở Phase 1

- **Mức:** ĐỎ. **Giai đoạn:** kiểm kiểu (M4). **Nguồn:** plan; ADR-018 (docs/DECISIONS.md).

## Giải thích
Giá trị có kiểu khác kiểu mong đợi tại một điểm ép kiểu (vế phải `≔`/`←`, đối số, `⏎`, nhánh `⎇`/`⌥`, đuôi khối, trường literal); sai số đối số của lời gọi; điều kiện không phải `bool`; `⊠`/`⊡` ngoài vòng lặp; kiểu không xác định được sau suy luận; `!` làm toán hạng; range mở dùng độc lập. Hai kiểu số khác nhau là E0302, không phải E0301. Literal ngoài phạm vi kiểu KHÔNG phải E0301 (đó là E0601, M7).

## Ví dụ sai và cách sửa
```
ƒ f() → bool ! ∅ { 1 }            // sai: `1` không phải `bool`
ƒ f() → bool ! ∅ { 1 > 0 }        // đúng
```
