# E0304 — lỗi trường struct/biến thể/tuple

- **Mức:** ĐỎ. **Giai đoạn:** kiểm kiểu (M4). **Nguồn:** plan; ADR-018 (docs/DECISIONS.md).

## Giải thích
Literal struct thiếu trường, thừa trường, trùng trường, trường không tồn tại; truy cập `.trường` không có; chỉ số tuple vượt số phần tử; pattern struct thiếu trường mà không có `..`; sai số thành phần của pattern biến thể/tuple. Chẩn đoán gợi ý thêm trường còn thiếu.

## Ví dụ sai và cách sửa
```
▢ P { x: i32, y: i32 }
ƒ f() → P ! ∅ { P { x: 1 } }               // sai: thiếu `y`
ƒ f() → P ! ∅ { P { x: 1, y: 2 } }         // đúng
```
