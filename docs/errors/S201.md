# S201 — `declassify` trên `Secret<T>`

- **Mức:** VÀNG. **Giai đoạn:** bộ quét secret (M9, theo dõi trên MIR). **Nguồn:** D13, GRIT_PLAN mục 5.

## Giải thích
`Secret<T>` không `Display`, không ghi log/mạng/tệp; `declassify` là chỗ DUY NHẤT lấy giá trị ra khỏi kiểu bảo vệ, nên mỗi lời gọi `declassify` trên `Secret<…>` được ghi nhận và báo VÀNG (D13). Tắt có kiểm soát bằng `#allow(S201, "lý do")`.

## Ví dụ
```
ƒ f(s: Secret<u32>) → u32 ! ∅ { s.declassify() }                    // cảnh báo
ƒ keep(s: Secret<u32>) → Secret<u32> ! ∅ { s }                      // không cảnh báo
```
