# E0307 — thiếu đường trả về

- **Mức:** ĐỎ. **Giai đoạn:** MIR (M5). **Nguồn:** plan M5; ADR-020 §4 (Q8: khối kết thúc bằng `;` trả `()`).

## Giải thích
Hàm có kiểu trả về khác `()` phải trả giá trị trên MỌI đường. Khi thân không có biểu thức cuối (khối kết thúc bằng `;`, hoặc đuôi là `⎇` không có `⇝`), bước hạ MIR tạo một lối "rơi khỏi cuối hàm"; nếu lối đó **tới được** trên đồ thị luồng điều khiển thì báo E0307. `⏎` ở mọi nhánh, lời gọi hàm `→ !`, hay vòng lặp vô hạn làm lối đó không tới được. Cũng là E0307 khi một hàm khai báo `→ !` có đường `⏎` tới được. Chỉ gấp hằng nghĩa đen `true`/`false` trong điều kiện; không suy luận giá trị (đó là M7).

## Ví dụ sai và cách sửa
```
ƒ f(c: bool) → i32 ! ∅ { ⎇ c { ⏎ 1; } }               // sai: c sai thì không trả gì
ƒ f(c: bool) → i32 ! ∅ { ⎇ c { ⏎ 1; } ⏎ 0; }          // đúng
```
