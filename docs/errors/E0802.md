# E0802 — Chữ ký không tương thích về hiệu ứng

- **Mức:** ĐỎ. **Giai đoạn:** hiệu ứng (M8). **Nguồn:** ADR-026 §1, semantics §4.

## Giải thích
Thành viên của `⊐ Trait for Kiểu` chỉ được khai hiệu ứng nằm trong tập mà thành viên tương ứng của trait cho phép (impl khai ÍT hơn thì được). Nhờ đó gọi qua trait an toàn: người gọi chỉ cần xét hiệu ứng khai trong trait. Hiệu ứng nằm trong KIỂU hàm khớp chính xác và đã bị bộ kiểm kiểu M4 bác bằng E0301 trước khi tới đây.

## Ví dụ sai và cách sửa
```
⊏ T { ƒ m(&self) ! ∅; }
⊐ T for S { ƒ m(&self) ! {io} { } }   // sai: trait cho ∅
⊏ T { ƒ m(&self) ! {io}; }
⊐ T for S { ƒ m(&self) ! ∅ { } }      // đúng
```
