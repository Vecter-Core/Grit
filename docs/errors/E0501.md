# E0501 — Chia sẻ không `Send` qua luồng

- **Mức:** ĐỎ. **Giai đoạn:** kiểm kiểu (M8, cùng bước giải ràng buộc trait). **Nguồn:** ADR-026 §2, semantics §11/§18.

## Giải thích
`spawn(f, a)` yêu cầu kiểu của `a` là `Send` (trait tự động trong prelude, suy theo CẤU TRÚC kiểu; không được viết `⊐ Send for`). Kiểu là `Send` nếu mọi thành phần đều `Send`. Phase 1 bảo thủ: mọi tham chiếu (`&T`, `&!T`), con trỏ thô và `Arena` đều KHÔNG `Send` (chưa có `'static`/luồng có phạm vi nên tham chiếu vào ngăn xếp người gọi sẽ treo, và `&!` cùng `&` trỏ một dữ liệu là đua dữ liệu); tham số kiểu chỉ `Send` khi có ràng buộc `T: Send`. Chia sẻ có kiểm soát sẽ đi qua kiểu đồng bộ (`Mutex`, atomics) ở nửa sau của M8.

## Ví dụ sai và cách sửa
```
ƒ w(r: &!u32) ! ∅ { }
ƒ main() ! ∅ { μx ≔ 5u32; spawn(w, &!x); }     // sai: &! chuyển sang luồng khác
ƒ w(n: u32) ! ∅ { }
ƒ main() ! ∅ { spawn(w, 5u32); }                // đúng: chuyển GIÁ TRỊ
```
