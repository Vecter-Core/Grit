# E0404 — Tham chiếu sống lâu hơn giá trị bị mượn

- **Mức:** ĐỎ. **Giai đoạn:** borrow checker (M6). **Nguồn:** ADR-023.

## Giải thích
Một tham chiếu còn dùng được sau khi giá trị nó trỏ tới đã hết phạm vi: trả `&local`/`&tạm`/`&tham_số_theo_giá_trị`; biến ở phạm vi ngoài giữ tham chiếu tới biến phạm vi trong; hoặc thân hàm vi phạm `RegionSig` của chữ ký (trả tham số có region khác với region đã hứa, trả `&'static` từ tham số). Không có "static promotion": `&1` trong thân hàm không tự thành `'static` (ADR-023 §11).

## Ví dụ sai và cách sửa
```
ƒ f() → &i32 ! ∅ { x ≔ 1; &x }                       // sai
ƒ f(x: &i32) → &i32 ! ∅ { x }                       // đúng: trả tham số tham chiếu
```
