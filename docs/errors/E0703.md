# E0703 — Đệ quy thiếu biến thể `↓` (hoặc `div`)

- **Mức:** ĐỎ. **Giai đoạn:** điều kiện dừng (M8). **Nguồn:** ADR-026 §2, semantics §21.

## Giải thích
Hàm nằm trong chu trình của đồ thị gọi (đệ quy trực tiếp hoặc tương hỗ, tính theo thành phần liên thông mạnh) phải có `↓` ở MỌI hàm của chu trình, hoặc khai hiệu ứng `div` để cố ý không dừng. Đệ quy đi qua giá trị hàm hoặc phương thức trait được tính bảo thủ (mọi hàm có thể được gọi gián tiếp) và không kiểm được biến thể giảm: khai `div` nếu cố ý.

## Ví dụ sai và cách sửa
```
ƒ f(n: u32) → u32 ! ∅ { f(n) }                                              // sai
ƒ fact(n: u32) → u64 ! ∅ ↓ n { ⎇ n == 0 { 1 } ⇝ { n as u64 *% fact(n - 1) } }  // đúng
```
