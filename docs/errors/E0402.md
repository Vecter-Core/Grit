# E0402 — Hai `&!` chồng nhau

- **Mức:** ĐỎ. **Giai đoạn:** borrow checker (M6). **Nguồn:** ADR-023.

## Giải thích
Hai khoản mượn duy nhất `&!` trên cùng một chỗ (hoặc trên hai chỗ chồng lấn: cả struct và trường của nó, cả mảng và phần tử — chỉ số luôn coi là chồng lấn mọi phần tử) cùng còn được dùng về sau. Theo NLL, khoản mượn chỉ còn hiệu lực tới LẦN DÙNG CUỐI; hai `&!` nối tiếp là hợp lệ. Hai trường khác nhau của một struct không chồng lấn.

## Ví dụ sai và cách sửa
```
ƒ f() ! ∅ { μx ≔ 1; a ≔ &!x; b ≔ &!x; *a ← 2; *b ← 3; }    // sai
ƒ f() → i32 ! ∅ { μx ≔ 1; a ≔ &!x; *a ← 2; b ≔ &!x; *b ← 3; x }  // đúng: a hết trước khi mượn b
```
