# E0321 — toán hạng của `?` không phải Option/Result (edition 2)

- **Mức:** ĐỎ. **Giai đoạn:** kiểm kiểu (M4). **Nguồn:** ADR-P2-09. **Edition:** 2.

## Giải thích
`e?` chỉ định nghĩa cho `e: Option<T>` hoặc `e: Result<T, E>`. Kiểu khác (số nguyên, `()`, tuple, struct…) ⇒ E0321. Kiểu của `e` phải ĐÃ BIẾT tại điểm `?` (kiểu còn là biến suy luận chưa giải cũng báo E0321 — thêm chú thích kiểu).

## Ví dụ sai và cách sửa
```
ƒ f(x: u32) → Option<u32> ! ∅ { v ≔ x?; Some(v) }      // sai: x là u32
ƒ f(x: u32) → Option<u32> ! ∅ { Some(x) }              // đúng
```
