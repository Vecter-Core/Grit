# E0201 — tên chưa định nghĩa

- **Mức:** ĐỎ. **Giai đoạn:** giải tên (M3). **Nguồn:** ADR-017 (d) mục 3, 4, 9.

## Giải thích
Một tên (biến, hàm, kiểu, biến thể, module, thành viên module, tên nhập bởi `⇲`) không tìm thấy trong phạm vi. Thứ tự tìm của đoạn
đầu đường dẫn: biến cục bộ (đường dẫn một đoạn) → tham số generics → tên của module hiện tại → tên module-tệp → prelude.
**Module `▦` lồng không kế thừa tên của module chứa nó.** Trong một khối, dùng biến trước khi khai báo bằng `≔` cũng là E0201
(thứ tự khai báo ITEM thì không quan trọng). `Self` chỉ có trong `⊏`/`⊐`; `self` chỉ trong hàm có tham số `self`; `result` chỉ trong `⊲`
(OPEN_QUESTIONS Q18). Mỗi vị trí dùng báo MỘT lỗi, không lan truyền.

## Ví dụ sai và cách sửa
```
ƒ f() → i32 ! ∅ { y }                       // sai: `y` chưa định nghĩa
ƒ f() → i32 ! ∅ { y ≔ 1; y }                // đúng
```
```
ƒ g() ! ∅ { }
▦ m { ƒ h() ! ∅ { g(); } }                  // sai: `m` không thấy `g` của module cha
▦ m { ⇲ main::g; ƒ h() ! ∅ { g(); } }       // đúng: nhập bằng đường dẫn tuyệt đối (tên tệp::tên)
```

## Giới hạn
`Kiểu::tên` với `tên` không phải biến thể (mục kết hợp trong `⊐`/`⊏`) KHÔNG được M3 kiểm — ghi `Res::Assoc` cho M4.
