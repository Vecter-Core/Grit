# E0701 — Vòng lặp không chứng minh được là dừng

- **Mức:** ĐỎ. **Giai đoạn:** điều kiện dừng (M8). **Nguồn:** ADR-026 §2, semantics §21.

## Giải thích
Vòng `⟳ cond { … }` cần một biến thể: người dùng viết `↓ v`, hoặc bộ kiểm tự suy từ một vế `a < b`, `a <= b`, `a > b`, `a >= b` của điều kiện (các vế nối bằng `∧`; `∨` và `!=` không dùng được). Thân phải làm biến thể giảm nghiêm ngặt và vẫn ≥ 0 trên MỌI cạnh quay lại đầu vòng. Vòng vô hạn `⟳ { … }` cần hiệu ứng `div`. Không chứng minh được thì ĐỎ: không có kiểm tra lúc chạy thay thế (D25).

## Ví dụ sai và cách sửa
```
ƒ f(n: u32) → () ! ∅ { μi ≔ 0u32; ⟳ i < n { } }                  // sai: thân không tiến
ƒ f(n: u32) → u32 ! ∅ { μi ≔ 0u32; ⟳ i < n { i ← i + 1; } i }    // đúng
ƒ f() → () ! ∅ { ⟳ { } }                                        // sai: thiếu div
ƒ f() → () ! {div} { ⟳ { } }                                    // đúng
```
