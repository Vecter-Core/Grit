# S101 — Secret nằm trong nguồn (mẫu nhận dạng)

- **Mức:** VÀNG (vẫn chạy, in cảnh báo nổi bật; `--deny-yellow` nâng thành ĐỎ). **Giai đoạn:** bộ quét secret (M9). **Nguồn:** GRIT_PLAN mục 5, ADR-028 §7.

## Giải thích
Literal chuỗi (hoặc comment) khớp một định dạng khoá/token phổ biến: khoá truy cập AWS (`AKIA…`/`ASIA…`), token GitHub (`ghp_…`, `github_pat_…`), Slack (`xox?-…`), khoá Google (`AIza…`), Stripe (`sk_live_…`), khối khoá riêng PEM, JWT. Secret cứng trong nguồn sẽ nằm nguyên văn trong binary. Tắt có kiểm soát bằng `#allow(S101, "lý do")` đặt trước item (lý do bắt buộc, không rỗng). **Giới hạn:** không phải bộ quét đầy đủ; secret mã hoá lồng, ghép chuỗi lúc chạy… không bị bắt (âm tính giả); chuỗi đúng định dạng nhưng là dữ liệu mẫu vẫn bị cảnh báo (dương tính giả).

## Ví dụ sai và cách sửa
```
ƒ key() → &str ! ∅ { k ≔ "AKIAIOSFODNN7EXAMPLE"; k }              // cảnh báo
#allow(S101, "khoá mẫu của tài liệu AWS")                           // đúng: tắt có lý do
```
