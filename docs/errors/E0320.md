# E0320 — `?` không khớp kiểu trả về của hàm bao (edition 2)

- **Mức:** ĐỎ. **Giai đoạn:** kiểm kiểu (M4). **Nguồn:** ADR-P2-09 (cài ADR-038 mục c, Q85). **Edition:** 2 (`rig.toml`: `edition = 2`, hoặc `gritc --edition=2`).

## Giải thích
`e?` là viết tắt của "lấy giá trị nếu thành công, ngược lại thoát sớm khỏi hàm bao":
- `e: Option<T>` trong hàm trả `Option<U>` ⇒ `⌥ e { Some(x) ↦ x, None ↦ ⏎ None }`; kiểu của `e?` là `T`.
- `e: Result<T, E>` trong hàm trả `Result<U, E>` (CÙNG `E`) ⇒ `⌥ e { Ok(x) ↦ x, Err(er) ↦ ⏎ Err(er) }`; kiểu của `e?` là `T`.

**Không có chuyển đổi ngầm** (không `From`): lỗi khác họ, khác kiểu lỗi, hoặc hàm bao không trả `Option`/`Result` ⇒ E0320. Muốn đổi họ/kiểu lỗi, viết tường minh (`e.ok_or(lỗi)?`, `e.map_err(f)?`).

## Ví dụ sai và cách sửa
```
ƒ f(x: Option<u32>) → Result<u32, u8> ! ∅ { v ≔ x?; Ok(v) }                // sai: Option trong hàm trả Result
ƒ f(x: Option<u32>) → Result<u32, u8> ! ∅ { v ≔ x.ok_or(1u8)?; Ok(v) }      // đúng: đổi họ tường minh
ƒ f() → Result<u32, i32> ! ∅ { v ≔ g()?; Ok(v) }                          // sai: g() trả lỗi u8, f trả lỗi i32
```
