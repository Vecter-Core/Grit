# E0102 — lồng nhau quá sâu

- **Mức:** ĐỎ (không phải ICE). **Giai đoạn:** parser (M2). **Nguồn:** `semantics.md` §26, ADR-014, ADR-015.

## Giải thích
Độ sâu cây (độ lồng của biểu thức, khối, kiểu, pattern, `▦`, cộng độ dài chuỗi toán tử/postfix/`as`) vượt `MAX_DEPTH` = 256
(định nghĩa duy nhất ở `gt_ast::MAX_DEPTH`). Parser dừng hẳn phân tích sau lỗi này. Giới hạn bảo vệ các pass đệ quy khỏi tràn stack.

## Cách sửa
Tách biểu thức con ra biến phụ bằng `≔`, hoặc chia khối/kiểu lồng sâu thành nhiều phần (thông báo lỗi luôn kèm gợi ý này).

```
ƒ f() → i32 ! ∅ { 1 + 1 + 1 + … (hơn 256 toán hạng) }     // sai: chuỗi phẳng cũng tính độ sâu
ƒ f() → i32 ! ∅ { a ≔ 1 + 1 + …; b ≔ a + 1 + …; a + b }    // đúng: tách bằng `≔`
```
