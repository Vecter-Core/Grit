# E0302 — ép kiểu số ngầm bị cấm (D1)

- **Mức:** ĐỎ. **Giai đoạn:** kiểm kiểu (M4). **Nguồn:** plan; ADR-018 (docs/DECISIONS.md).

## Giải thích
Không có chuyển đổi số ngầm: `i32` → `i64`, số nguyên → số thực, hai toán hạng số khác kiểu đều là lỗi. Dùng `as T` (chẩn đoán đưa gợi ý sửa dạng máy áp được). Lưu ý `x as T < y` phải viết `(x as T) < y` (Q16c).

## Ví dụ sai và cách sửa
```
ƒ f(a: i32) → f64 ! ∅ { a }              // sai
ƒ f(a: i32) → f64 ! ∅ { a as f64 }       // đúng
```
