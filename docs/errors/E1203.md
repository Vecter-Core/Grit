# E1203 — định danh trộn bảng chữ (homoglyph)

- **Mức:** ĐỎ. **Giai đoạn:** lexer (M1). **Nguồn:** D15; ADR-009/ADR-010.

## Giải thích
Một định danh hoặc lifetime trộn các bảng chữ khác nhau (không kể Common/Inherited), ví dụ chữ `а` Cyrillic (`U+0430`) lẫn Latin: `xа` trông giống `xa` nhưng là tên khác. `µ` (`U+00B5`, MICRO SIGN) cũng bị chặn vì trông giống `μ` dành riêng của ngôn ngữ. Định danh THUẦN một bảng chữ lạ (vd. toàn Cyrillic) vẫn hợp lệ — đó là giới hạn đã biết (docs/KNOWN_LIMITATIONS.md).

## Ví dụ sai và cách sửa
```
ƒ f() → i32 ! ∅ { xа ≔ 1; xa }     // sai: `xа` có `а` Cyrillic trộn Latin
ƒ f() → i32 ! ∅ { xa ≔ 1; xa }     // đúng
```
