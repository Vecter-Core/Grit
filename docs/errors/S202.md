# S202 — Giá trị nhạy cảm chảy tới sink `io`

- **Mức:** VÀNG. **Giai đoạn:** bộ quét secret (M9, taint trên MIR). **Nguồn:** D13, GRIT_PLAN mục 5.

## Giải thích
Giá trị lấy từ `Secret<T>` (hoặc kết quả `declassify`, hoặc bất cứ thứ gì tính từ chúng) được truyền cho một lời gọi có hiệu ứng `io` (sink log/mạng/tệp). Taint tính theo THÂN HÀM, không theo luồng điều khiển (bảo thủ ⇒ có dương tính giả), và không xuyên hàm (hàm được gọi nhận `Secret` qua tham số kiểu `Secret<…>` sẽ được kiểm riêng).

## Ví dụ
```
ƒ sink(s: Secret<u32>) ! {io} { }
ƒ f(s: Secret<u32>) ! {io} { sink(s); }                             // cảnh báo
ƒ log(x: u32) ! {io} { }
ƒ f(n: u32) ! {io} { log(n); }                                      // không cảnh báo
```
