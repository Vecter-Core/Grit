# E1204 — nguồn không ở dạng chuẩn NFC

- **Mức:** ĐỎ. **Giai đoạn:** lexer (M1). **Nguồn:** D15; ADR-009/ADR-010.

## Giải thích
Nguồn không ở dạng chuẩn hoá Unicode NFC. Cùng một chữ có thể viết bằng một điểm mã (`é` = `U+00E9`) hoặc hai (`e` + `U+0301`); hai cách cho tên khác nhau theo byte nhưng giống nhau trên màn hình. Grit đòi NFC để một tên chỉ có một cách viết.

## Ví dụ sai và cách sửa
```
ƒ f() → i32 ! ∅ { cafe<U+0301> ≔ 1; 1 }     // sai: `e` (U+0065) rồi dấu sắc rời U+0301 (hiển thị giống `é`)
ƒ f() → i32 ! ∅ { café ≔ 1; 1 }     // đúng: `é` = U+00E9 (chạy `gritc fmt` hoặc chuẩn hoá NFC ở trình soạn thảo)
```
