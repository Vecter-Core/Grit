# E0303 — `==`/`≠` trên số thực bị cấm (D4)

- **Mức:** ĐỎ. **Giai đoạn:** kiểm kiểu (M4). **Nguồn:** plan; ADR-018 (docs/DECISIONS.md).

## Giải thích
So sánh bằng/khác trên `f32`/`f64` bị chặn vì NaN và sai số làm nó gần như luôn là lỗi. So sánh thứ tự (`<`, `≤`, `>`, `≥`) vẫn hợp lệ; muốn so gần đúng thì viết hiệu có ngưỡng.

## Ví dụ sai và cách sửa
```
ƒ f(a: f64, b: f64) → bool ! ∅ { a == b }                    // sai
ƒ f(a: f64, b: f64) → bool ! ∅ { (a - b) < 0.001 ∧ (b - a) < 0.001 }   // đúng
```
