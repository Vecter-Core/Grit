# E1201 — ký tự điều khiển bidi (Trojan Source)

- **Mức:** ĐỎ. **Giai đoạn:** lexer (M1). **Nguồn:** D15; ADR-009/ADR-010.

## Giải thích
Nguồn Grit chứa ký tự điều khiển chiều văn bản: `U+202A–202E`, `U+2066–2069`, cộng LRM/RLM/ALM (`U+200E`, `U+200F`, `U+061C`). Chúng đảo thứ tự HIỂN THỊ của mã mà không đổi thứ tự LOGIC, nên người đọc thấy một chương trình còn trình biên dịch chạy chương trình khác ("Trojan Source"). Bị cấm ở MỌI nơi, kể cả trong comment và chuỗi (fail-closed).

## Ví dụ sai và cách sửa
```
ƒ f() → i32 ! ∅ { 1 } // <U+202E> evil  // sai: U+202E (RLO) nằm trong comment (ở đây viết <U+202E> thay cho ký tự thật)
ƒ f() → i32 ! ∅ { 1 } // evil         // đúng
```
Muốn có ký tự đó trong chuỗi, dùng escape `\u{202E}`.
