# E1001 — `unsafe` thiếu bằng chứng; con trỏ thô ngoài `⚠`

- **Mức:** ĐỎ. **Giai đoạn:** nghĩa vụ (M7; cài ở M9 khi gritc thành cổng thật). **Nguồn:** D21, D22, Q12, Q13.

## Giải thích
`⚠` chỉ hợp lệ khi MỌI nghĩa vụ của nó (hợp lệ con trỏ, căn lề, không alias, độ sống, không data race…) được GIẢI bởi bộ giải, kèm mệnh đề `⊢` (D21: không có cơ chế "tin tôi đi"). Phase 1 chưa có nghĩa vụ `⊢` nào giải được nên MỌI `⚠` trong mã người dùng đều là chưa giải ⇒ E1001, kể cả khối rỗng; chỉ `lib/core` có `intrinsic trusted` (D22). Kiểu con trỏ thô `*□ T` / `*μ T` chỉ hợp lệ BÊN TRONG `⚠`: có trong chữ ký hàm, trường ADT, hằng/static hay biến gán ngoài `⚠` cũng là E1001 (Q13).

## Ví dụ sai và cách sửa
```
ƒ f(p: usize) → i32 ! ∅ { ⚠ { raw_read(p) } }      // sai: ⚠ chưa giải được
ƒ f(p: *□ i32) → i32 ! ∅ { 0 }                      // sai: con trỏ thô ngoài ⚠
ƒ f(x: &i32) → i32 ! ∅ { *x }                       // đúng: tham chiếu an toàn
```
