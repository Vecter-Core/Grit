# N0905 — Nhiên liệu còn sau vòng lặp hạ thành runtime

- **Mức:** GHI CHÚ (không đổi exit code). **Giai đoạn:** nghĩa vụ (M7). **Nguồn:** dogfood 2026-10-13 (lệnh 1c).

## Giải thích
Mẫu "nhiên liệu": khi biến thể `↓` của vòng không chứng minh được bằng quan hệ chỉ số (vd bước tiến `i ← i + f(..)` hay đệ quy tương hỗ), dùng một biến đếm `fuel` giảm 1 mỗi vòng và điều kiện `fuel > 0`; M8 chứng minh dừng nhờ `fuel`. Gọi `core::fuel_left(fuel)` NGAY SAU vòng: nếu vòng thoát vì cạn nhiên liệu (`fuel == 0`) thì ĐÂY là lỗi (chương trình có thể bị cắt cụt kết quả) nên abort kiểu riêng `fuel_exhausted` (mã thoát 70) thay vì lặng lẽ coi như xong. `core::fuel_left` là một `Assert` loại `Fuel`: nếu M7 chứng minh được `fuel > 0` thì check bị xoá, ngược lại GIỮ lúc chạy và báo ghi chú N0905 (xuất hiện trong báo cáo "check còn lại" với loại `fuel`).

## Ví dụ
```
ƒ f(n: u64) → u64 ! ∅ {
  μfuel ≔ n; μi ≔ 0u64;
  ⟳ fuel > 0u64 ∧ i < 1000u64 ↓ fuel { fuel ← fuel - 1u64; i ← i + 1u64; }
  core::fuel_left(fuel);      // n quá nhỏ ⇒ abort fuel_exhausted
  i
}
```
