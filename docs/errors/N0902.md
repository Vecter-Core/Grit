# N0902 — Hậu điều kiện hạ thành runtime

- **Mức:** GHI CHÚ (không đổi exit code). **Giai đoạn:** nghĩa vụ (M7). **Nguồn:** ADR-025.

## Giải thích
`⊲` chưa chứng minh được ở một điểm thoát: kiểm trước MỌI `Return` của hàm.

## Ví dụ
```
ƒ f(x: i32) → i32 ! ∅ ⊲ result > 0 { x }
```
