# E0401 — Dùng sau move

- **Mức:** ĐỎ. **Giai đoạn:** borrow checker (M6). **Nguồn:** ADR-023.

## Giải thích
Một giá trị không phải `Copy` đã bị move (vào biến khác, vào hàm, vào struct/tuple/`Some`, qua `self`, hoặc ra khỏi một trường) rồi lại bị đọc, mượn, ghi trường hoặc move lần nữa — trên BẤT KỲ đường nào có thể tới đó (kể cả qua cạnh lùi của vòng lặp, hoặc khi chỉ một nhánh `⎇`/`⌥` đã move). Gán lại toàn bộ biến (`μb`) làm nó khởi tạo lại. Move một trường rồi dùng TRƯỜNG KHÁC thì hợp lệ (move một phần, ADR-023 §3).

## Ví dụ sai và cách sửa
```
ƒ f() → i32 ! ∅ { b ≔ mk(); eat(b); peek(&b) }          // sai: b đã move vào eat
ƒ f() → i32 ! ∅ { μb ≔ mk(); eat(b); b ← mk(); b.v }  // đúng: gán lại
```
