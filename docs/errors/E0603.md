# E0603 — Chỉ số / khoảng cắt lát ngoài biên chắc chắn

- **Mức:** ĐỎ. **Giai đoạn:** nghĩa vụ số nguyên (M7). **Nguồn:** ADR-025.

## Giải thích
Chỉ số `a[i]` luôn `≥ len` (hoặc khoảng `a[x..y]` luôn vi phạm `x ≤ y ≤ len`) trên mọi đường tới điểm đó. Chỉ số chưa biết thì giữ kiểm lúc chạy (N0602).

## Ví dụ sai và cách sửa
```
ƒ f() → i32 ! ∅ { a ≔ [1, 2, 3]; a[3] }                // sai
ƒ f() → i32 ! ∅ { a ≔ [1, 2, 3]; a[2] }                // đúng
```
