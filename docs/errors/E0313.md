# E0313 — kiểu lang dùng sai (`Secret`/`Cap`)

- **Mức:** ĐỎ. **Giai đoạn:** kiểm kiểu (M4). **Nguồn:** plan; ADR-018 (docs/DECISIONS.md).

## Giải thích
`Secret<T>` và `Cap<T>` không giả mạo được (D13, D29): không tạo bằng struct literal ngoài lib/core, và không được khai báo `⊐ Copy for` chúng (chúng không bao giờ `Copy`). Lấy `Cap` từ nguồn hợp lệ (vd `root_fs()`), chuyển bằng move.

Mở rộng (mục 2, lệnh 2026-10-17): hàm INTRINSIC của lib/core (thân prelude không có MIR) KHÔNG được dùng làm giá trị hàm (`f ≔ shl; f(1, 40)`): mọi nghĩa vụ theo lớp được sinh ở điểm gọi TRỰC TIẾP nên gọi qua con trỏ sẽ né kiểm tra (precondition, E0310, E0405, E0502, E0501…). Gọi trực tiếp, cú pháp phương thức, và hàm Grit thường bọc intrinsic vẫn dùng được; riêng `Atomic` giữ E0503.

## Ví dụ sai và cách sửa
```
ƒ f() ! ∅ { c ≔ Cap { v: 1 }; }       // sai: giả mạo capability
ƒ f() ! ∅ { c ≔ root_fs(); }           // đúng
```
