# E0503 — Memory ordering của atomic không hợp lệ hoặc không viết thẳng

- **Mức:** ĐỎ. **Giai đoạn:** hiệu ứng (M8 nửa 2, mức MIR). **Nguồn:** ADR-027 §4.

## Giải thích
Mọi thao tác của `Atomic<T>` nhận `AtomicOrdering` TƯỜNG MINH (không có mặc định: thiếu là lỗi arity thường). Đối số ordering phải truy ngược được về MỘT biến thể viết thẳng (`AtomicOrdering::Acquire`, hoặc biến cục bộ gán đúng một lần từ nó); tham số hay giá trị tính toán thì không đoán ⇒ E0503. Tổ hợp hợp lệ: `load` ∈ {Relaxed, Acquire, SeqCst}; `store` ∈ {Relaxed, Release, SeqCst}; `compare_exchange`: thứ tự thất bại ∈ {Relaxed, Acquire, SeqCst} và không mạnh hơn thứ tự thành công. `swap`/`fetch_add`/`fetch_sub` nhận mọi ordering.

## Ví dụ sai và cách sửa
```
ƒ f(a: &Atomic<u32>) → u32 ! ∅ { a.load(AtomicOrdering::Release) }   // sai
ƒ f(a: &Atomic<u32>) → u32 ! ∅ { a.load(AtomicOrdering::Acquire) }   // đúng
```
