# E0314 — `!` ở vị trí không hợp lệ

- **Mức:** ĐỎ. **Giai đoạn:** kiểm kiểu (M4). **Nguồn:** plan; ADR-018 (docs/DECISIONS.md).

## Giải thích
Kiểu `!` (không có giá trị) chỉ hợp lệ làm kiểu trả về và nhánh phân kỳ. Không được làm đối số kiểu (`Option<!>`), kiểu trường, phần tử mảng hay phần tử tuple. Dùng làm toán hạng là E0301.

## Ví dụ sai và cách sửa
```
▢ S { x: ! }                  // sai
ƒ die() → ! ! {div} { core::abort("x") }   // đúng
```
