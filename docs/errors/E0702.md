# E0702 — Biến thể `↓` không giảm nghiêm ngặt hoặc không bị chặn dưới

- **Mức:** ĐỎ. **Giai đoạn:** điều kiện dừng (M8). **Nguồn:** ADR-026 §2, semantics §21.

## Giải thích
Biến thể `↓ v` (của vòng lặp hoặc của hàm đệ quy) phải thoả hai điều trên mọi cạnh quay lại / mọi lời gọi đệ quy: `v` mới < `v` cũ, và `0 ≤ v` cũ. Chứng minh bằng chính bộ giải khoảng+zone của M7 (bộ vét cạn kiểm chứng). Biểu thức `↓` phải tuyến tính theo tham số/biến nguyên và `xs.len()`. Vòng for-in hữu hạn tự giảm nên `↓` ở đó bị bỏ qua. Biến thể giảm mà có thể âm khi vòng còn tiếp tục thì KHÔNG hợp lệ.

## Ví dụ sai và cách sửa
```
ƒ f() → () ! ∅ { μi ≔ 5i32; ⟳ i > -100 ↓ i { i ← i - 1; } }     // sai: i có thể âm
ƒ f() → i32 ! ∅ { μi ≔ 10i32; ⟳ i > 0 ↓ i { i ← i - 1; } i }   // đúng
```
