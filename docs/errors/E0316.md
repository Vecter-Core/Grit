# E0316 — Lượng từ ngoài hợp đồng

- **Mức:** ĐỎ. **Giai đoạn:** kiểm kiểu (M4). **Nguồn:** ADR-025 §6 (Giang, 2026-10-08).

## Giải thích
`∀ x ∈ a..b : P` và `∃ x ∈ a..b : P` chỉ có nghĩa trong HỢP ĐỒNG: tiền điều kiện `⊳`, hậu điều kiện `⊲`, biến thể `↓`, bất biến vòng lặp `⋈`. Dùng chúng trong biểu thức thường (thân hàm, điều kiện `⎇`, vế phải của `≔`) là lỗi của chương trình người dùng, không phải lỗi nội bộ của compiler. Nếu muốn kiểm một tính chất trên khoảng trong mã chạy, hãy viết vòng lặp `⟳`.

## Ví dụ sai và cách sửa
```
ƒ f(n: i32) → bool ! ∅ { ∀ i ∈ 0..n : i < n }                       // sai: lượng từ trong thân
ƒ f(n: i32) → i32 ! ∅ ⊳ ∀ i ∈ 0..n : i < 100 { n }                  // đúng: trong hợp đồng
```
