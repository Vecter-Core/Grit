# E0405 — Con trỏ thoát Arena (D27)

- **Mức:** ĐỎ. **Giai đoạn:** borrow checker (M6). **Nguồn:** ADR-023.

## Giải thích
Tham chiếu cấp từ một `Arena` còn được dùng sau khi Arena sang "phiên bản" mới: bị `Drop`/hết phạm vi, bị move, bị gán đè, hoặc bị `reset` (tạo `&!` Arena) — mà không có kiểm tra lúc chạy. MỘT mã cho mọi thao tác này (ADR-023 §10, Q32). Arena là tham số `&'r Arena` thì trả `&'r T` hợp lệ.

## Ví dụ sai và cách sửa
```
ƒ f() → &i32 ! {mem} { a ≔ Arena::new(); a.alloc(1) }          // sai: a chết khi hàm trả về
ƒ f<'r>(a: &'r Arena) → &'r i32 ! {mem} { a.alloc(1) }  // đúng
```
