# E0310 — thiếu capability (D28, D29)

- **Mức:** ĐỎ. **Giai đoạn:** kiểm kiểu (M4.5). **Nguồn:** plan D27–D29; ADR-019; `docs/spec/regions.md`.

## Giải thích
Capability `Cap<Fs|Net|Env|Clock|Alloc|…>` là kiểu affine không giả mạo được (E0313). Dữ liệu chảy theo kiểu: muốn dùng thao tác cần capability thì phải CÓ một giá trị `Cap<K>`, và giá trị đó chỉ đến được hàm qua tham số (chữ ký). Cách duy nhất để có capability mà không nhận qua tham số là gọi một NGUỒN GỐC — hàm trả kiểu chứa `Cap<…>` mà không nhận `Cap<…>` nào (vd `root_fs()`, `Host::fs()`) — và theo D29 chỉ `main` (hàm cấp cao `main` của một tệp, không phải thành viên impl/trait, không lồng module) được gọi nguồn gốc. Mọi chỗ khác gọi (hoặc chỉ tham chiếu) nguồn gốc đều là E0310: trong hàm thường, phương thức, hàm generic, nhánh/vòng lặp, khởi tạo `□`/`■` (không có capability toàn cục). Chia nhỏ (`fs.sub("d")`) hợp lệ vì nhận `&Cap<Fs>`. Kiểm sau khi kiểu giải xong nên đúng với hàm generic (`ƒ mk<T>() → T` thành `Cap<Fs>` cũng là nguồn gốc).

## Ví dụ sai và cách sửa
```
ƒ size() → usize ! {io} { root_fs().read("a").len() }                  // sai: sinh Cap<Fs> ngoài main
ƒ size(fs: &Cap<Fs>) → usize ! {io} { fs.read("a").len() }          // đúng: nhận qua chữ ký
ƒ main() → usize ! {io} { size(&root_fs()) }                            // đúng: main là nguồn gốc
```
