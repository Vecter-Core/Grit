# N0901 — Tiền điều kiện hạ thành runtime

- **Mức:** GHI CHÚ (không đổi exit code). **Giai đoạn:** nghĩa vụ (M7). **Nguồn:** ADR-025.

## Giải thích
`⊳` của callee chưa chứng minh được tại điểm gọi: chèn một lời gọi thân `⊳` rồi `Assert` ngay trước lời gọi.

## Ví dụ
```
ƒ pos(n: i32) → i32 ! ∅ ⊳ n > 0 { n }
ƒ g(x: i32) → i32 ! ∅ { pos(x) }
```
