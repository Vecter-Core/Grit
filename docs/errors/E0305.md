# E0305 — `⌥` không đầy đủ (D6) và pattern của `let` phân rã có thể bị từ chối (edition 2, ADR-P2-10)

- **Mức:** ĐỎ. **Giai đoạn:** kiểm kiểu (M4). **Nguồn:** plan; ADR-018 (docs/DECISIONS.md).

## Giải thích
Mọi `⌥` phải phủ hết giá trị của kiểu (thuật toán ma trận Maranget). Số nguyên/`char` vét cạn theo khoảng nên `..0`, `0..=9`, `10..` phủ đủ `i32`; `str`, số thực và các kiểu mờ cần `_` hoặc nhánh tên. Literal đơn lẻ không phủ cả miền. Nhánh sau nhánh bắt-tất-cả không phải lỗi ở M4 (mã chết là việc của M5). Chẩn đoán nêu giá trị chưa được phủ.

## Ví dụ sai và cách sửa
```
ƒ f(b: bool) → i32 ! ∅ { ⌥ b { true ↦ 1 } }                // sai: thiếu `false`
ƒ f(b: bool) → i32 ! ∅ { ⌥ b { true ↦ 1, false ↦ 0 } }     // đúng
```
