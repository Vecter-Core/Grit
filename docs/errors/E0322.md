# E0322 — alternative của or-pattern bind biến (edition 2, v1)

- **Mức:** ĐỎ. **Giai đoạn:** kiểm kiểu (M4). **Nguồn:** ADR-P2-11. **Edition:** 2.

## Giải thích
`p | q | …` thử lần lượt các alternative; nếu bất kỳ alternative nào khớp, nhánh được chọn. Ở v1 MỖI alternative chỉ được KIỂM KHỚP (literal, khoảng, biến thể, `_`, tuple/struct/biến thể con của chúng), KHÔNG được bind biến: bind trong or-pattern đòi mọi alternative bind cùng tập biến cùng kiểu và
gán chúng từ chỗ nguồn khác nhau — đó là chỗ tinh tế liên quan move/borrow nên để một lô sau, có oracle riêng. Dùng `_` thay cho biến, hoặc tách thành các nhánh `⌥` riêng.

## Ví dụ sai và cách sửa
```
⌥ o { Some(v) | None ↦ 1u32 }       // sai: `v` là biến
⌥ o { Some(_) | None ↦ 1u32 }       // đúng
⌥ x { 1 | y ↦ 0u32, _ ↦ 1u32 }      // sai: `y` là biến mới
```
