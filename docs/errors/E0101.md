# E0101 — lỗi cú pháp (token bất ngờ, thiếu dấu, từ khoá/ký hiệu dành riêng dùng sai chỗ)

- **Mức:** ĐỎ (exit 1, không sinh mã, không chạy). **Giai đoạn:** lexer + parser (M1/M2).
- **Nguồn:** `docs/spec/grammar.ebnf`, `semantics.md` §12–§15, §20, §25b.

## Giải thích
Chương trình không khớp grammar. Parser báo MỘT lỗi cho mỗi vị trí hỏng rồi khôi phục (ở `;`, `}` hoặc đầu item) để báo tiếp lỗi
khác; AST của chương trình có lỗi cú pháp KHÔNG được dùng (fail-closed). Các dạng gồm: thiếu `}`/`;`, token sai chỗ, từ khoá cứng
(`self`, `Self`, `in`, `as`, `for`, `true`, `false`) hoặc ký hiệu dành riêng (`μ`, `\extern`, `\where`) dùng làm tên, comment khối
`/* */` (cấm ở Phase 1), `=` đứng riêng, và `x as T < y` thiếu ngoặc (Q16c).

## Ví dụ sai và cách sửa
```
ƒ f(x: i32, y: i64) → bool ! ∅ { x as i64 < y }      // sai: `i64 <` mở danh sách tham số kiểu
ƒ f(x: i32, y: i64) → bool ! ∅ { (x as i64) < y }    // đúng
```
Với `x as T < y` parser kèm gợi ý `machine-applicable` bọc `(x as T)` (hai edit nguyên tử).

```
ƒ f() → i32 ! ∅ { 1 + 2        // sai: thiếu `}`
ƒ f() → i32 ! ∅ { 1 + 2 }      // đúng
```
