# E0901 — Hợp đồng chắc chắn sai

- **Mức:** ĐỎ. **Giai đoạn:** hợp đồng (M7, ADR-025 §6). **Nguồn:** ADR-025.

## Giải thích
Tiền điều kiện `⊳` của callee luôn sai tại một lời gọi trực tiếp; hoặc hậu điều kiện `⊲` luôn sai ở một điểm thoát; hoặc bất biến `⋈` luôn sai khi tới đầu vòng lặp. `⊳` chưa chứng minh được thì KHÔNG phải lỗi: hạ thành kiểm lúc chạy tại điểm gọi + N0901.

## Ví dụ sai và cách sửa
```
ƒ pos(n: i32) → i32 ! ∅ ⊳ n > 0 { n }
ƒ f() → i32 ! ∅ { pos(0) }                         // sai
ƒ f() → i32 ! ∅ { pos(5) }                         // đúng
```
