# E0203 — truy cập item private

- **Mức:** ĐỎ. **Giai đoạn:** giải tên (M3). **Nguồn:** ADR-017 (d) mục 5; `semantics.md` §10.

## Giải thích
Mặc định mọi thứ là private; `◈` làm item thấy được ở mọi nơi. Item private thấy ở module định nghĩa và MỌI module con của nó, nhưng
không thấy ở module anh em hay tệp khác. Áp dụng cho đường dẫn dùng trực tiếp lẫn `⇲`; tên nhập cũng private trừ khi `◈ ⇲`
(tái xuất khẩu). Nhãn của chẩn đoán trỏ tới định nghĩa (có thể ở tệp khác) và nhắc thiếu `◈`. Quyền truy cập trường private là việc
của M4 (cần kiểu).

## Ví dụ sai và cách sửa
```
// a.gt
ƒ secret() → i32 ! ∅ { 1 }                  // sai nếu b.gt gọi a::secret()
◈ ƒ secret() → i32 ! ∅ { 1 }                // đúng: công khai
```
