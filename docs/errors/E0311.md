# E0311 — `⊐` không hợp lệ

- **Mức:** ĐỎ. **Giai đoạn:** kiểm kiểu (M4). **Nguồn:** plan; ADR-018 (docs/DECISIONS.md).

## Giải thích
Impl thiếu hàm của trait, thừa hàm, chữ ký khác trait, chồng lấn với impl khác cùng trait và cùng kiểu, hoặc `⊐ Copy for` kiểu có trường không `Copy` / không phải struct/enum của người dùng.

## Ví dụ sai và cách sửa
```
⊏ T { ƒ a(&self) → i32 ! ∅; ƒ b(&self) ! ∅; }
⊐ T for S { ƒ a(&self) → i32 ! ∅ { 1 } }   // sai: thiếu `b`
```
