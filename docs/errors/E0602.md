# E0602 — Chia/phần dư cho 0 chắc chắn

- **Mức:** ĐỎ. **Giai đoạn:** nghĩa vụ số nguyên (M7). **Nguồn:** ADR-025.

## Giải thích
Mẫu số của `/` hoặc `%` bằng 0 trên mọi đường tới điểm đó (hằng 0, biến đã biết bằng 0, hoặc nhánh mà điều kiện ép mẫu số = 0). Mẫu số chưa biết thì KHÔNG phải lỗi: check được giữ lúc chạy kèm ghi chú N0603.

## Ví dụ sai và cách sửa
```
ƒ f(a: i32) → i32 ! ∅ { a / 0 }                        // sai
ƒ f(a: u32, b: u32) → u32 ! ∅ { ⎇ b > 0 { a / b } ⇝ { 0 } }   // đúng
```
