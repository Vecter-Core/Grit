# E1002 — `#lang` ngoài lib/core

- **Mức:** ĐỎ. **Giai đoạn:** kiểm kiểu (M4). **Nguồn:** plan; ADR-018 (docs/DECISIONS.md).

## Giải thích
Thuộc tính `#lang(tên)` đánh dấu kiểu/trait đặc biệt cho compiler (option, copy, range, secret, cap) và chỉ hợp lệ trong lib/core (prelude). Ở chương trình người dùng nó bị từ chối nên không thể giả mạo kiểu lang; kiểu bị gắn thuộc tính vẫn là kiểu thường.

## Ví dụ sai và cách sửa
```
#lang(secret)
▢ S { x: i32 }       // sai: `#lang` ngoài lib/core
```
