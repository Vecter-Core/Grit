# E0403 — `&!` chồng `&`

- **Mức:** ĐỎ. **Giai đoạn:** borrow checker (M6). **Nguồn:** ADR-023.

## Giải thích
Một khoản mượn duy nhất `&!` còn hiệu lực trong khi chỗ đó (hoặc phần chồng lấn) bị mượn chung `&` hoặc bị ĐỌC trực tiếp, hoặc ngược lại một `&` còn được dùng khi tạo `&!`. Đọc giá trị `Copy` của biến đang bị `&!` mượn cũng là truy cập xung đột.

## Ví dụ sai và cách sửa
```
ƒ f() → i32 ! ∅ { μx ≔ 1; r ≔ &x; w ≔ &!x; *w ← 2; *r }     // sai
ƒ f() → i32 ! ∅ { μx ≔ 1; r ≔ &x; use_i(*r); w ≔ &!x; *w ← 2; x }  // đúng: r hết trước w
```
