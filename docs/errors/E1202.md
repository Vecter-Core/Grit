# E1202 — ký tự vô hình / zero-width / điều khiển lạ

- **Mức:** ĐỎ. **Giai đoạn:** lexer (M1). **Nguồn:** D15; ADR-009/ADR-010.

## Giải thích
Nguồn chứa ký tự không nhìn thấy: zero-width (`U+200B–200D`, `U+2060`), BOM `U+FEFF` (kể cả ở đầu tệp), ký tự điều khiển, khoảng trắng lạ, hoặc `\r` lẻ (chỉ `\r\n` là xuống dòng). Hai định danh trông giống hệt nhưng khác byte là cửa hậu dễ nhất; vì vậy cấm ở MỌI nơi, kể cả trong chuỗi/comment (muốn dùng trong chuỗi thì viết `\u{…}`).

## Ví dụ sai và cách sửa
```
ƒ f() → i32 ! ∅ { ab<U+200B> ≔ 1; 1 }     // sai: U+200B (zero-width space) nằm trong định danh (viết <U+200B> thay cho ký tự thật)
ƒ f() → i32 ! ∅ { ab ≔ 1; 1 }      // đúng
```
