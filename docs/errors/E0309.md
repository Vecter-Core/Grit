# E0309 — ràng buộc trait không thoả / không có phương thức / mơ hồ

- **Mức:** ĐỎ. **Giai đoạn:** kiểm kiểu (M4). **Nguồn:** plan; ADR-018 (docs/DECISIONS.md).

## Giải thích
Gọi hàm generic với kiểu không có `⊐ Trait for Kiểu`; gọi phương thức không tồn tại trên kiểu (sau chuỗi autoderef); hoặc nhiều trait cùng cung cấp phương thức cùng tên cho một kiểu mà gọi không phân biệt được. Phương thức kế thừa (inherent) được ưu tiên trước phương thức trait (ADR-018 §2).

## Ví dụ sai và cách sửa
```
⊏ Area { ƒ area(&self) → i32 ! ∅; }
ƒ f(x: i32) → i32 ! ∅ { total(&x) }          // sai: `i32` không có `⊐ Area`
```
