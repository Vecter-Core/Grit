# E0406 — Gán hoặc move khi đang bị mượn

- **Mức:** ĐỎ. **Giai đoạn:** borrow checker (M6). **Nguồn:** ADR-023.

## Giải thích
Ghi vào, gán đè, hoặc move ra khỏi một chỗ trong khi có khoản mượn chồng lấn còn được dùng về sau. Ghi qua chính tham chiếu đang giữ khoản mượn (`*p ← v`) không xung đột với khoản vay `p` đang giữ.

## Ví dụ sai và cách sửa
```
ƒ f() → i32 ! ∅ { μx ≔ 1; r ≔ &x; x ← 2; *r }                // sai
ƒ f() → i32 ! ∅ { μx ≔ 1; r ≔ &x; y ≔ *r; x ← 2; y +% x }  // đúng
```
