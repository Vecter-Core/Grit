# E0204 — vòng phụ thuộc module

- **Mức:** ĐỎ. **Giai đoạn:** giải tên (M3). **Nguồn:** ADR-017 (d) mục 6; `semantics.md` §10.

## Giải thích
Đồ thị phụ thuộc giữa các module phải không có vòng. Có cạnh S → T khi S chứa một tham chiếu đã phân giải (đường dẫn hoặc `⇲`) tới
item của module T ≠ S mà T không phải S hay hậu duệ của S. Tham chiếu tới prelude không tạo cạnh. Mỗi thành phần liên thông mạnh có
hơn một module bị báo MỘT lần, liệt kê module theo thứ tự tên, nhãn tại các vị trí tham chiếu tạo vòng (có thể ở nhiều tệp).
Cha → con và con → cha (đường dẫn tuyệt đối) cùng tồn tại không tạo vòng.

## Ví dụ sai và cách sửa
```
// a.gt: ◈ ƒ fa() ! ∅ { b::fb(); }
// b.gt: ◈ ƒ fb() ! ∅ { a::fa(); }          // sai: a ↔ b
// sửa: chuyển phần chung sang module thứ ba mà cả hai cùng dùng (c.gt), không ai dùng lại a hoặc b
```
