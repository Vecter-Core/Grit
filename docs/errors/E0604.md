# E0604 — Ép kiểu mất thông tin chắc chắn

- **Mức:** ĐỎ. **Giai đoạn:** nghĩa vụ số nguyên (M7). **Nguồn:** ADR-025.

## Giải thích
`x as T` với `T` hẹp hơn / khác dấu mà giá trị của `x` LUÔN nằm ngoài khoảng của `T` trên mọi đường tới điểm đó (D1). Giá trị chưa biết: giữ kiểm lúc chạy (N0604).

## Ví dụ sai và cách sửa
```
ƒ f() → u8 ! ∅ { 300 as u8 }                           // sai
ƒ f() → u8 ! ∅ { 200 as u8 }                           // đúng
```
