# E0319 — phép số thực chưa hỗ trợ / bị cấm ở Phase 1

- **Mức:** ĐỎ. **Giai đoạn:** kiểm kiểu (M4). **Nguồn:** ADR-035 §B (Q70, Q73), Giang 2026-10-14.

## Giải thích
`f64` có số học IEEE-754 (`+ - * /`), so sánh thứ tự và các hàm `sqrt/to_i64/to_bits/is_nan` + `core::f64_from_bits`. Những thứ sau bị E0319:
1. **`as` từ số thực sang số nguyên/ký tự/bool:** dùng `x.to_i64()` (trả `Option<i64>`; NaN, ±∞ hoặc ngoài miền ⇒ `None`; phần thập phân cắt về 0). Mất thông tin và hành vi ngoài miền không được che giấu.
2. **`f32` (literal, `as f32`):** chưa hỗ trợ ở Phase 1; dùng `f64`.
3. **`%` trên số thực:** cần `fmod` nằm ngoài bảng runtime đóng của IR Guard.
(`==`/`≠` trên số thực vẫn là E0303, D4.)

## Ví dụ sai và cách sửa
```
x ≔ 1.5f64;  n ≔ x as i64;                       // sai: dùng ⌥ x.to_i64() { Some(v) ↦ v, None ↦ 0 }
y ≔ 1.5f32;                                       // sai: dùng 1.5f64
z ≔ 7.0f64 % 2.0f64;                              // sai: chưa hỗ trợ
```
