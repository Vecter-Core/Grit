# E0318 — `Vec<T>` với `T` cần drop

- **Mức:** ĐỎ. **Giai đoạn:** kiểm kiểu (M4). **Nguồn:** ADR-032 phụ lục A (3b) và B.

## Giải thích
`Vec<'a, T>` nằm trong `Arena` và KHÔNG chạy destructor khi Arena `reset`/kết thúc. Nếu `T` cần drop (là `Arena`, có `Drop`, hoặc chứa thành phần như vậy) thì tài nguyên của phần tử sẽ bị bỏ sót. Lỗi báo ở lời gọi thành viên của `Vec` (`new`, `push`, …) khi `T` cần drop. Tham số kiểu `T` trong hàm generic được coi là CẦN drop trừ khi có ràng buộc `T: Copy` (fail-closed).

## Ví dụ sai và cách sửa
```
▢ Holder { a: Arena, n: u8 }
v.push(Holder { a: Arena::new(), n: 1u8 });   // sai: Holder chứa Arena
ƒ mk<'a, T>(a: &'a Arena, w: T) → Vec<'a, T> ! {mem} { Vec::new(a) }   // sai: T không Copy
ƒ mk<'a, T: Copy>(a: &'a Arena, w: T) → Vec<'a, T> ! {mem} { Vec::new(a) }   // đúng
```
