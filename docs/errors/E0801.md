# E0801 — Hiệu ứng suy ra không nằm trong khai báo

- **Mức:** ĐỎ. **Giai đoạn:** hiệu ứng (M8). **Nguồn:** ADR-026 §1, semantics §4.

## Giải thích
Hàm phải khai báo ⊇ hiệu ứng suy ra. Hiệu ứng suy ra là hợp hiệu ứng khai báo của mọi hàm được gọi: gọi trực tiếp, qua giá trị hàm (hiệu ứng nằm trong kiểu `ƒ(…) → T ! {…}`), hoặc qua phương thức trait (hiệu ứng khai trên thành viên trait). Hiệu ứng đi qua mọi tầng gọi và qua đệ quy tương hỗ. Hàm `! ∅` gọi hàm có hiệu ứng cũng là E0801. Khai thừa hiệu ứng thì hợp lệ. (Vòng vô hạn thiếu `div` do E0701 sở hữu.)

## Ví dụ sai và cách sửa
```
ƒ out() → () ! {io} { }
ƒ f() → () ! ∅ { out(); }        // sai
ƒ f() → () ! {io} { out(); }    // đúng
```
