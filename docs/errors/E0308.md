# E0308 — gán vào chỗ bất biến (D5)

- **Mức:** ĐỎ. **Giai đoạn:** kiểm kiểu (M4). **Nguồn:** plan; ADR-018 (docs/DECISIONS.md).

## Giải thích
Biến, tham số và trường qua tham chiếu chung `&T` bất biến theo mặc định. Gán `←` vào chúng, mượn duy nhất `&!` một biến bất biến, hoặc gọi phương thức `&!self` trên receiver bất biến đều là lỗi; khai báo `μx ≔ …` hoặc dùng tham chiếu `&!`.

## Ví dụ sai và cách sửa
```
ƒ f(x: i32) → i32 ! ∅ { x ← 2; x }       // sai: tham số bất biến
ƒ f() → i32 ! ∅ { μx ≔ 1; x ← 2; x }      // đúng
```
