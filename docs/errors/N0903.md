# N0903 — Lượng từ có biên chạy lúc chạy

- **Mức:** GHI CHÚ (không đổi exit code). **Giai đoạn:** nghĩa vụ (M7). **Nguồn:** ADR-025.

## Giải thích
`∀/∃ i ∈ a..b : P` trong hợp đồng chưa giải được tĩnh: thân hợp đồng là một vòng lặp thuần (tối đa `b − a` bước).

## Ví dụ
```
ƒ f(n: i32) → i32 ! ∅ ⊳ ∀ i ∈ 0..n : i < 100 { n }
```
