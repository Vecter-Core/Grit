# E0407 — Move ra khỏi tham chiếu, chỉ số hoặc giá trị có Drop

- **Mức:** ĐỎ. **Giai đoạn:** borrow checker (M6). **Nguồn:** ADR-023.

## Giải thích
Move ra khỏi chỗ đi qua `*` (tham chiếu, con trỏ thô), `[i]` hay lát; hoặc move một TRƯỜNG ra khỏi giá trị có `⊐ Drop for`/`Arena` (drop của nó cần cả giá trị). Kiểu `Copy` thì sao chép được; muốn lấy ra kiểu không `Copy` hãy dùng `&` hoặc đổi quyền sở hữu. Move một phần khỏi kiểu KHÔNG có Drop được phép (ADR-023 §3).

## Ví dụ sai và cách sửa
```
ƒ f(r: &B) → B ! ∅ { *r }                                  // sai
ƒ f(r: &B) → i32 ! ∅ { r.v }                              // đúng: i32 là Copy
```
