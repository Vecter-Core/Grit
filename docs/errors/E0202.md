# E0202 — định nghĩa trùng

- **Mức:** ĐỎ. **Giai đoạn:** giải tên (M3). **Nguồn:** ADR-017 (d) mục 2.

## Giải thích
Mỗi module có MỘT không gian tên chung cho item (hàm, struct, enum, trait, alias, const, static), module `▦` con, tên nhập bởi `⇲`
và biến thể enum (biến thể cũng là tên trong module chứa enum — OPEN_QUESTIONS Q19). Trùng tên → MỘT chẩn đoán cho mỗi (module, tên),
nêu số lần và gắn nhãn mọi vị trí. Cũng là E0202: biến thể/trường trùng trong một enum/struct, tham số hàm hoặc generics trùng,
thành viên trùng trong một khối `⊏`/`⊐`, và cùng tên được gán hai lần trong một pattern. Cùng tên ở HAI module khác nhau là hợp lệ.

## Ví dụ sai và cách sửa
```
ƒ f() → i32 ! ∅ { 1 }
ƒ f() → i32 ! ∅ { 2 }                       // sai: `f` định nghĩa hai lần
ƒ f() → i32 ! ∅ { 1 }
ƒ g() → i32 ! ∅ { 2 }                       // đúng
```
