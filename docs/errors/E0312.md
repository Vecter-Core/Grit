# E0312 — đệ quy đa hình vượt ngưỡng instance

- **Mức:** ĐỎ. **Giai đoạn:** kiểm kiểu (M4). **Nguồn:** plan; ADR-018 (docs/DECISIONS.md).

## Giải thích
Đơn hình hoá lazy (ADR-018 §1) gặp hàm generic tự gọi mình với kiểu ngày càng lớn (`f<T>` gọi `f<(T,)>`…) nên số instance vô hạn; vượt độ sâu 64 thì báo lỗi thay vì lặp vô hạn. Đệ quy giữ nguyên kiểu thì bình thường.

## Ví dụ sai và cách sửa
```
ƒ f<T>(x: T) ! ∅ { f((x,)); }      // sai: T → (T,) → ((T,),) → …
```
