# S102 — Literal chuỗi entropy cao gán cho tên gợi ý secret

- **Mức:** VÀNG. **Giai đoạn:** bộ quét secret (M9). **Nguồn:** GRIT_PLAN mục 5, ADR-028 §7.

## Giải thích
Tên (biến, tham số, hằng) chứa `key`, `token`, `secret`, `api`, `passw`, `pwd` được gán một literal chuỗi dài (≥ 12 ký tự) có entropy Shannon ≥ 3,3 bit/ký tự; hoặc tên mật khẩu (`passw`/`pwd`) với literal ≥ 8 ký tự, entropy ≥ 2,5 và có chữ số. Literal đã bị S101 bắt thì không báo lại. **Giới hạn:** ngưỡng là kinh nghiệm; literal rỗng, ngắn hoặc entropy thấp không bị cảnh báo; tên không gợi ý thì không bị xét.

## Ví dụ
```
ƒ f() → &str ! ∅ { api_key ≔ "x8F3kQ9zLp2Vw7Rm"; api_key }          // cảnh báo
ƒ f() → &str ! ∅ { name ≔ "x8F3kQ9zLp2Vw7Rm"; name }                // không cảnh báo (tên không gợi ý)
```
