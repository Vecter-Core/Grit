# E0601 — Tràn số chắc chắn

- **Mức:** ĐỎ. **Giai đoạn:** nghĩa vụ số nguyên (M7). **Nguồn:** ADR-025.

## Giải thích
Phép `+ - *` (nguyên thường), `-x` có dấu hoặc `MIN / -1` cho kết quả ngoài phạm vi kiểu trên MỌI đường thực thi tới điểm đó, hoặc một literal nguyên không vừa kiểu của nó (`256u8`, `128i8`). Literal ngoài phạm vi là lỗi ngay cả trong mã chết (chương trình đã sai kiểu); các trường hợp còn lại chỉ báo khi điểm đó TỚI ĐƯỢC theo phân tích (trạng thái ≠ ⊥). Cách sửa: dùng kiểu rộng hơn, `+% +^ +?`, hoặc kiểm điều kiện trước.

## Ví dụ sai và cách sửa
```
ƒ f() → u8 ! ∅ { 255u8 + 1u8 }                 // sai: luôn tràn
ƒ f(a: u8) → u8 ! ∅ { ⎇ a < 100 { a + 100 } ⇝ { 0 } }   // đúng: chứng minh được không tràn
```
